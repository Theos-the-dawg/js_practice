# Part 1: Math Exercises

## Exercise 1: Basic Calculator

Write a program that stores two numbers and prints:

- Sum (+)
- Difference (-)
- Product (*)
- Quotient (/)
- Remainder (%)

```javascript
let num1 = 20;
let num2 = 6;
```

**Expected Output**

```
Sum: 26
Difference: 14
Product: 120
Quotient: 3.3333
Remainder: 2
```

## Exercise 2: Area of a Rectangle

Given:

```javascript
let length = 12;
let width = 8;
```

Calculate the area.

Formula:

```
Area = length * width
```
